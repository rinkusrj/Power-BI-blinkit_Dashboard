# Power-BI-blinkit_Dashboard
# Blinkit Analysis Project


# Steps in the Project:

1.	Requirement Gathering/ Business Requirements: Define objectives and success criteria.
2.	Data Walkthrough: Understand the data structure and its alignment with requirements.
3.	Data Correction: Identify and fix inconsistencies or errors in the data.
4.	Data Cleansing/ Quality Check: Ensure the data is accurate, complete, and ready for analysis.
5.	Data Modeling: Organize data into logical structures for efficient querying and analysis.
6.	Data Processing: Transform raw data into a usable format for reporting.
7.	DAX Calculations: Develop advanced calculations using DAX for insightful metrics.
8.	Dashboard Layout Planning: Design intuitive and user-friendly dashboard structures.
9.	Charts Development and Formatting: Create and format visualizations to represent data effectively.
10.	Dashboard/ Reporting Development: Build and deploy Power BI dashboards for interactive reporting.
11.	Insights Generation: Analyze data to extract actionable insights and recommendations.

# Business Objective:

Conduct a comprehensive analysis of Blinkit’s:
	Sales performance
	Customer satisfaction
	Inventory distribution
Outcome: Identify key insights and optimization opportunities using KPIs and Power BI visualizations.

# KPIs Requirements:

1.	Total Sales: Revenue generated from all items sold.
2.	Average Sales: Revenue per transaction.
3.	Number of Items Sold: Total items sold during the analysis period.
4.	Average Rating: Customer satisfaction based on item ratings.

# Chart Requirements:

1.	Total Sales by Fat Content: 

•	Objective: Assess the impact of fat content on sales.
•	Metrics: Analyze how Total Sales, Average Sales, Number of Items, and Average Rating vary with fat content.
•	Chart Type: Donut Chart.

2.	Total Sales by Item Type:

•	Objective: Evaluate performance of different item categories.
•	Metrics: Assess KPIs (Total Sales, Average Sales, etc.).
•	Chart Type: Bar Chart.

3.	Fat Content by Outlet for Total Sales:

•	Objective: Compare sales across outlets based on fat content.
•	Metrics: Examine KPI variations.
•	Chart Type: Stacked Column Chart.

4.	Total Sales by Outlet Establishment:
•	Objective: Analyze how outlet age/type 
•	Chart Type: Line Chart.

5.	Sales by Outlet Size:
•	Objective: Study the correlation between outlet size and sales.
•	Chart Type: Donut/Pie Chart.

6.	Sales by Outlet Location:
•	Objective: Understand geographic sales distribution.
•	Chart Type: Funnel Map.

7.	All Metrics by Outlet Type:
•	Objective: Provide a complete overview of KPIs (Total Sales, Average Sales, etc.) across outlet types.
•	Chart Type: Matrix Card.
